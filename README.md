# 🧬 Biology Tracker

A web application designed to track and monitor biological data, experiment metrics, and observations.

---

## 🚀 Features

- **Data Tracking:** Record and review biological metrics cleanly.
- **Automated CI/CD:** Integrated GitHub Actions for HTML syntax validation and automated checks.
- **Security Protocols:** Protected main branch, automated secret scanning, and dependency monitoring.

---

## 🛠️ Security & Integrity

This repository adheres to strict security and quality guidelines:
- **PR Security Checks:** All pull requests run syntax verification and secret detection before merging.
- **CodeQL Scanning:** Automated static analysis scans for code vulnerabilities.
- **Branch Protection:** Direct pushes to `main` are disabled to ensure code quality.

---

## 💻 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **CI/CD:** GitHub Actions (`.github/workflows/pr-security.yml`)
